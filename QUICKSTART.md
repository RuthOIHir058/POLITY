# POLITY Quick Start

This guide assumes no prior POLITY experience. It takes you from a clean clone to a verified simulation, a modified policy, and a first interpretation of the output.

## 1. Install Git and Python

Install Git and CPython 3.11, 3.12, or 3.13. Confirm both commands work:

```bash
git --version
python --version
```

On Linux or macOS, the interpreter command may be `python3`. On Windows, the Python launcher may be `py`.

## 2. Clone POLITY

```bash
git clone https://github.com/RuthOlHir058/POLITY.git
cd POLITY
```

## 3. Create an isolated environment

Linux or macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Windows PowerShell:

```powershell
py -3.13 -m venv .venv
.venv\Scripts\Activate.ps1
```

Your prompt normally shows `(.venv)` after activation.

## 4. Install the project and verification tools

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements-dev.txt
```

Confirm the command is available:

```bash
polity --version
```

Expected version line:

```text
POLITY Engine 1.0.0
```

## 5. Verify the checkout

Run the automated test suite:

```bash
python -m pytest
```

The V1.0.0 release contains 60 passing tests. Then verify the publication database and deterministic behavior:

```bash
python -m tools.validation.check_schema
python -m tools.validation.check_determinism --years 20
```

A successful determinism check reports exact equality and a canonical result fingerprint.

## 6. Run your first simulation

```bash
polity KEN --start-year 2015 --years 5
```

The first positional argument is a country code. `KEN` selects Kenya. `--start-year 2015` loads and calibrates the country at that baseline. `--years 5` advances five annual steps and prints years 2016 through 2020.

The columns mean:

| Column | Meaning |
|---|---|
| `year` | New state year after one annual update |
| `growth` | Real annual GDP growth generated by the model |
| `gdp_pc` | Modeled GDP per capita in current baseline currency units |
| `inflation` | Inflation ratio shown as a percentage |
| `unemployment` | Unemployment ratio shown as a percentage |
| `debt_gdp` | Public debt divided by GDP |
| `life_exp` | Modeled life expectancy in years |
| `conflict` | Logistic conflict-risk score from 0% to 100% |

These are scenario outputs, not forecasts.

## 7. Save the annual results

```bash
polity KEN --start-year 2015 --years 20 \
  --output results/kenya_baseline.csv
```

Open `results/kenya_baseline.csv` in a spreadsheet or analysis tool. The CSV includes macroeconomic, social, conflict, and Tier-3 reference metrics for every simulated year.

## 8. Inspect why a value changed

```bash
polity KEN --start-year 2015 --years 3 --audit
```

The CLI prints audit entries whose severity is notable or higher. Each entry names the changed variable, delta, and a human-readable note. The Python API exposes every audit entry, including severity `none`, together with numerical cause contributions.

Example:

```python
from engine.cli import DEFAULT_POLICY
from engine.core.initialize_country import initialize_country
from engine.core.simulation_engine import SimulationEngine

state = initialize_country("KEN", 2015)
result = SimulationEngine.step(state, DEFAULT_POLICY)

for entry in result.audit_log:
    if entry.variable == "gdp_growth":
        print(entry.value)
        for cause, magnitude in entry.causes:
            print(cause, magnitude)
```

## 9. Modify a policy

Copy the baseline file so the published example remains unchanged:

```bash
cp configs/baseline_policy.json configs/my_policy.json
```

On Windows, use File Explorer or:

```powershell
Copy-Item configs\baseline_policy.json configs\my_policy.json
```

Edit `configs/my_policy.json`. The six expenditure shares must still sum to 1.0. For example, this reallocation increases education and infrastructure while reducing transfers and administration:

```json
{
  "tax_rate": 0.40,
  "total_expenditure_gdp": 0.24,
  "health_share": 0.15,
  "education_share": 0.25,
  "infrastructure_share": 0.25,
  "social_transfers_share": 0.15,
  "admin_share": 0.10,
  "military_share": 0.10,
  "inflation_target": 0.02,
  "trade_policy": 0.00
}
```

Run it:

```bash
polity KEN --start-year 2015 --years 20 \
  --policy-file configs/my_policy.json \
  --output results/kenya_my_policy.csv
```

Education investment enters a 15-year queue, so a higher education share does not immediately increase human capital. Infrastructure affects the growth equation immediately through the annual capital-accumulation term. This difference in timing is intentional and auditable.

## 10. Compare two policies fairly

Every scenario should begin from the same initial state. The simulation does not mutate that state, so this is safe:

```python
from engine.cli import DEFAULT_POLICY
from engine.core.initialize_country import initialize_country
from engine.core.simulation_engine import SimulationEngine

initial = initialize_country("KEN", 2015)
reform = DEFAULT_POLICY.with_updates(
    education_share=0.25,
    infrastructure_share=0.25,
    social_transfers_share=0.15,
    admin_share=0.10,
)

baseline_results = SimulationEngine.simulate(initial, DEFAULT_POLICY, 20)
reform_results = SimulationEngine.simulate(initial, reform, 20)

print(baseline_results[-1].derived["gdp_per_capita"])
print(reform_results[-1].derived["gdp_per_capita"])
```

You can also run the packaged comparison example:

```bash
python examples/compare_policies.py --country KEN --start-year 2015 --years 20
```

A difference between scenarios is a consequence of the model equations and input policies. It is not an estimated real-world treatment effect.

## 11. Interpret the result object

A one-year result has four parts:

```python
result.state
result.derived
result.reference
result.audit_log
```

Use `state` for variables that persist into the next year. Use `derived` for values recomputed from the state and current flow equations. Use `reference` for display metrics that never feed back into the engine. Use `audit_log` to trace causes.

Important timing rules:

- Current conflict risk affects the next year's GDP and capacity path.
- Current education spending enters human capital after 15 queue advances.
- Trade openness is computed prospectively for the growth term but committed at its specified annual phase.
- Automatic stabilizers can replace the requested policy with one deterministic effective policy under extreme debt or unemployment conditions.

## 12. Try another country or year

```bash
polity MNG --start-year 2015 --years 10
```

Not every country-year can initialize because the source warehouse is incomplete. POLITY fails explicitly when a required field cannot be found rather than inserting an undocumented value. See `docs/verification/release_verification.json` for the countries that completed the publication 20-year check.

## 13. Know the main limitation

The software tests and deterministic checks pass, but the historical calibration target does not. The bundled data cannot support the exact 2025 acceptance test, and the documented 2024 proxy produced zero all-indicator passes among 113 comparable countries. Read [VERIFICATION_REPORT.md](VERIFICATION_REPORT.md) before using the model in research.
